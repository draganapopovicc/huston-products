# 🏭 Houston Products Inc. – Custom WordPress Website

A fully custom WordPress website built for [Houston Products Inc.](https://houstonproductsinc.com/), using a custom theme, Advanced Custom Fields (ACF), and custom post types.

## 💼 About Houston Products Inc.

Houston Products, Inc is a family-owned company committed to providing the utmost in customer service.
A manufacturer of rubber grippers to meet the demanding needs of the conveyor and packaging machinery industries.

## 🧰 Technologies Used

- WordPress CMS
- PHP (custom theme)
- HTML5 & SCSS
- JavaScript / jQuery
- Advanced Custom Fields (ACF)
- Custom Post Types (CPT)

## 🛠 Features

- Custom WordPress theme built from scratch (no page builder)
- Custom Post Types
- Dynamic content fields using ACF
- Mobile-friendly responsive design
